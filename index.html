Settings

Sending knowledge to GitHub

To file submissions straight from this phone, AstroBot needs a GitHub token with permission to open issues on one repository. It is kept in this browser only, is never sent anywhere except github.com, and you can clear it below. Use a fine-grained token scoped to this repository with Issues: read and write and nothing else.

About

Astrology is not a predictive science. Nothing here is advice about health, money, law or relationships.

Tap a planet to put it here or take it away. R marks it retrograde where that is a choice: the Sun and Moon never are, and Rahu and Ketu always are.
